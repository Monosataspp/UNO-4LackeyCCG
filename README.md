<br>This is the UNO plugin for LackeyCCG.
# Features
* 2010 Card layout (like the one used in UNO & Friends).
* Standard UNO Deck (with Draw Two, Reverse, Skip, Wild, and Wild Draw Four).
* Variety of different UNO Decks (such as Express and All Wild!).
* Lots of different Action Cards from many sources (such as Reverse Skip and All Draw Two).
